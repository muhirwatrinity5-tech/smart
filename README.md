# Smart Study Planner

This is a Python program that helps students to plan their studies.

## What it does
 Add study session (date, subject, hours)
 View all sessions
 Search by subject
 View total hours studied
 Save to file study_log.txt

## Files in this repo
 cw1.doc.py - main Python code
 study_log.txt - data file
 ssm.pdf - coursework report
